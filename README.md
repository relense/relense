## What I'm building: Otterbond

[Otterbond](https://otterbond.app) is a budget and savings app built for two people, aimed at Portugal first. The headline feature is a single daily number: what you can spend today until payday, after bills and savings are covered.

- **Stack:** TypeScript end to end. Node.js + GraphQL + Prisma + PostgreSQL API, Expo/React Native mobile app, Astro landing site with a web client, Stripe billing on the web only.
- **Things I'm proud of:** a payday-cycle model that makes the daily number correct for people paid on the 25th, a rules-based insights engine (bill price changes, missing salary, duplicate charges) with a stored lifecycle, month locking with an end-of-month "wrap", and free/paid gating designed so the free tier stays useful.
- **Also on the site:** 18 free calculators for Portugal (net salary, recibos verdes, IRS, IMT, unemployment benefit, pension gap, FIRE), each sharing its calculation module with the app.
- Android on Google Play, iOS in review, web live.
